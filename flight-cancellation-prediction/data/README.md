# Data

The CSV files are not stored in this repository because of their size.

1. Go to the Kaggle dataset *Airline Delay and Cancellation Data, 2009–2018*:
   https://www.kaggle.com/datasets/yuanyuwendymu/airline-delay-and-cancellation-data-2009-2018
2. Download `2017.csv` and `2018.csv`.
3. Put both files in this folder (when running locally) or in a Google Drive folder, and point `DATA_DIR` in the notebook to it.
   The default in Colab is `/content/drive/MyDrive/flights-data`.
